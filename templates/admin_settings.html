불일치 판정

같은 영상·같은 변수에 대한 계측자들의 값 중 (최댓값 − 최솟값)이 이 값을 넘으면 불일치로 판정합니다. 모든 변수에 동일하게 적용되는 전역 값입니다.
값을 바꾸면 전체 영상이 즉시 재분류됩니다. 계측값 자체는 바뀌지 않습니다 — 이 값은 계측자 간 차이를 얼마까지 같다고 볼지를 정하는 보고용 기준입니다.

계측 화면

기본 {{ defaults.render_max_px }}px. 값을 키우면 계측 정밀도가 올라가지만 저장 용량과 전송량이 늘어납니다. 이미 등재된 영상에는 소급 적용되지 않습니다 (다시 업로드해야 새 해상도로 렌더됩니다).
기본 {{ defaults.idle_lock_ms }}ms(60초). 이 시간 동안 조작이 없으면 화면을 잠그고 경과 시간 측정을 멈춥니다 — 자리를 비운 시간이 계측 소요시간에 섞이지 않게 합니다.
기본 {{ defaults.idle_phase1_ms }}ms(10초). 1단계 안내에도 반응이 없으면 '새로 시작'만 가능한 2단계로 넘어갑니다.
