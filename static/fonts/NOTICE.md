# Bundled fonts

`Freesentation-*.woff2` — **Freesentation**, released by the Korea
Communications Agency / Freesentation project under the
**SIL Open Font License 1.1 (OFL-1.1)**.

The fonts are bundled rather than loaded from a CDN because the tool is
designed to run on an isolated hospital network with no outbound internet
access.

> **Before publishing this repository:** place the official `OFL.txt` from the
> Freesentation distribution in this directory. OFL-1.1 requires the licence
> text to accompany any redistribution of the font files; this notice alone
> does not satisfy it. If you would rather not redistribute the fonts, delete
> the `.woff2` files and the `@font-face` rules at the top of
> `static/style.css` — the stylesheet falls back to the system UI stack.

The licence of the fonts is independent of the licence of this software.
